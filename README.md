# Virginia Justice Data: source documents

This repository holds copies of the public documents behind the numbers on
[VirginiaJusticeData.org](https://virginiajusticedata.org). Every number on the site
links to its source. Each source has up to three links: the agency's original, an
archived copy on the Internet Archive's Wayback Machine, and the copy kept here.

## What is here

- The documents are in this repository's **Releases**, one batch per year (for example,
  `sources-2026`). They are not in the code view.
- Each file is named by its source ID, as listed on the site's Sources page.
- Each batch includes a `SHA256SUMS` file, so anyone can confirm a file is exactly the
  one we used.
- Every file is an **unaltered copy** of the document as the agency published it. Each is
  credited to that agency on the site's Sources page: the Virginia Criminal Sentencing
  Commission, the Virginia Parole Board, the Office of the Executive Secretary of the
  Supreme Court of Virginia, the Virginia State Police, the State Compensation Board,
  and others.
- When an agency later revises or removes a document, the version we used stays here,
  and the change is noted on the Sources page.

## Why

Agency web pages move, change and disappear. Keeping the exact files means readers and
critics can check any figure on the site against the document it came from.

These are copies of public records, kept for verification and public reference.
Virginia Justice Data is not affiliated with any of the agencies whose documents appear
here.
